# Pratik Rai

I build local-first software: AI agent infrastructure, iPhone apps, and desktop tools. I care about what happens behind the interface—how agents use tools, how data survives a failed write, and whether an app still works without a connection.

Based in Nagpur, India. Open to 2027 new-grad and internship roles in AI systems and backend engineering.

[Portfolio](https://www.pratikrai.dev) · [Résumé](https://www.pratikrai.dev/resume) · [X](https://x.com/PratikRai0101) · [LinkedIn](https://linkedin.com/in/pratikrai0101) · [Email](mailto:raipratik0101@gmail.com)

### Selected work

- **[Milemark](https://github.com/PratikRai0101/Milemark)** — a SwiftUI running app that prints routes as thermal-paper receipts, with pace charts, photo treatments and a paper-tear gesture.
- **[Vantage](https://github.com/PratikRai0101/vantage)** — a native 3D Formula 1 replay: seventeen cars at Suzuka, three cameras, recorded timing and time-aligned telemetry.
- **[Monolith](https://github.com/PratikRai0101/cron)** — a local-first focus tracker. Sessions build layers of stone, with a contribution grid and portable JSON history.
- **[NeoSwarm](https://github.com/PratikRai0101/neoswarm)** — a local multi-agent orchestrator: a team-lead agent delegates to parallel workers through a Python runtime, with desktop and terminal interfaces.
- **[Varq](https://github.com/PratikRai0101/Varq)** — a native macOS e-reader for EPUB, PDF and CBZ. Books, reading progress, highlights and notes stay on your machine.
- **[LocalCanvas](https://github.com/PratikRai0101/LocalCanvas)** — an offline Excalidraw whiteboard for macOS, with portable drawings and atomic file saves through Rust.

Also: [OpenLog](https://github.com/PratikRai0101/open-log), [AgentReady Commerce](https://github.com/PratikRai0101/agentready-commerce), and [Evo2 Variant Analysis](https://github.com/PratikRai0101/Evo2_Variant_Analysis_BNB). [Demos & case studies →](https://www.pratikrai.dev/work)
