◆ **recent apps**

* **[Milemark](https://github.com/PratikRai0101/Milemark)** — a SwiftUI running app that records routes with MapKit and prints them as thermal-paper receipts. Route, ASCII, pace and photo treatments, a paper-tear gesture, and receipts you can keep or share. [Demo & case study](https://www.pratikrai.dev/work/milemark).
* **[Monolith](https://github.com/PratikRai0101/cron)** — a local-first competence tracker. Focus sessions, tasks and manual logs build a layered block of stone and a 26-week contribution grid. React Native + Expo, on-device storage, JSON export. [Demo & case study](https://www.pratikrai.dev/work/monolith).
* **[Vantage](https://github.com/PratikRai0101/vantage)** — a native 3D replay of the 2024 Japanese Grand Prix: seventeen cars at Suzuka, three cameras, recorded timing and time-aligned telemetry. React Native + Three.js, with Expo GL on Android and Metal/WebGPU on iOS. [Demo & case study](https://www.pratikrai.dev/work/vantage).
* **[Varq](https://github.com/PratikRai0101/Varq)** — an open-source macOS e-reader for EPUB, PDF and CBZ. SwiftUI + SwiftData, with books, reading progress, highlights and notes stored locally. [Case study](https://www.pratikrai.dev/work/varq).
* **[LocalCanvas](https://github.com/PratikRai0101/LocalCanvas)** — an offline Excalidraw whiteboard for macOS. Drawings stay portable `.excalidraw` files, with atomic autosaves through Rust. [Case study](https://www.pratikrai.dev/work/localcanvas).

Milemark, Monolith and Vantage are in development; the demos show the working apps, not App Store releases.

◆ **workflow**

I build with agents as much as I build them. My loop: write a tight spec → delegate the draft to coding agents → review every diff → back it with tests. I use **monocode**, **pi** and **opencode**, and keep responsibility for the code I ship.

Terminal-first, with Arch (Omarchy + Hyprland) in my setup. I care about portable data, software that works offline, and small systems I can inspect and test.
